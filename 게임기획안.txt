스네이크 게임 기획안

1. 프로젝트명
Snake Game

한 줄 소개:
먹이를 먹으며 몸을 길게 성장시키고, 벽이나 자신의 몸에 부딪히지 않도록 오래 생존하는 아케이드 게임

2. 기획 목적
간단한 웹 게임을 직접 제작하면서 HTML, CSS, JavaScript의 기본적인 동작 구조를 익히는 것을 목표로 한다.

주요 학습 요소:
- 키보드 입력 처리
- 캐릭터 이동
- 랜덤 위치 생성
- 충돌 판정
- 점수 계산
- 게임 상태 관리
- localStorage를 이용한 데이터 저장
- 반응형 웹 구현

3. 게임 컨셉
플레이어는 화면 속 뱀 캐릭터를 조작한다.

게임판에 랜덤으로 나타나는 먹이를 먹으면 뱀의 몸이 한 칸씩 길어지고 점수가 올라간다.

다음 상황에서 게임이 종료된다.
- 벽에 부딪힌 경우
- 자신의 몸에 부딪힌 경우

먹이를 많이 먹을수록 뱀의 이동 속도가 조금씩 빨라져 난이도가 올라간다.

4. 게임 진행 방식

[시작]
게임 화면에 다음 내용을 표시한다.

SNAKE GAME
먹이를 먹고 최대한 오래 살아남으세요!
START

START 버튼을 누르면 게임이 시작된다.

[조작]
PC:
- ↑ 위 이동
- ↓ 아래 이동
- ← 왼쪽 이동
- → 오른쪽 이동

모바일:
- 게임 화면 아래에 터치 방향 버튼을 제공한다.

[먹이]
- 게임판의 빈 공간에 먹이가 무작위로 생성된다.
- 먹이는 뱀의 몸 위에 생성되지 않는다.
- 뱀이 먹이를 먹으면 점수가 올라간다.
- 뱀의 몸 길이가 1칸 증가한다.
- 새로운 먹이가 다시 랜덤한 위치에 생성된다.

5. 점수 시스템
- 먹이 1개당 10점
- 현재 점수는 게임 화면 상단에 표시한다.
- 최고 점수도 함께 표시한다.

예시:
SCORE 80
BEST 150

6. 난이도
처음에는 비교적 천천히 움직이도록 한다.

먹이를 일정 개수 이상 먹거나 점수가 높아질수록 이동 속도가 조금씩 빨라지도록 한다.

예시:
- 0~40점: 느림
- 50~90점: 보통
- 100~190점: 빠름
- 200점 이상: 매우 빠름

속도는 갑자기 크게 변하지 않고 자연스럽게 증가하도록 한다.

7. 게임 오버 조건

1) 벽 충돌
뱀의 머리가 게임판 바깥으로 나가거나 벽에 닿으면 게임 오버가 된다.

2) 자기 몸 충돌
뱀의 머리가 자신의 몸에 닿으면 게임 오버가 된다.

8. 게임 오버 화면

게임 종료 시 화면 중앙에 다음 내용을 표시한다.

GAME OVER

SCORE
현재 점수

BEST
최고 점수

[다시 시작]

다시 시작 버튼을 누르면 페이지 전체를 새로고침하지 않고 게임 상태를 초기화한 뒤 다시 플레이할 수 있도록 한다.

9. 최고 점수 기능
- 최고 점수는 브라우저 localStorage에 저장한다.
- 브라우저를 새로고침하거나 다시 실행해도 최고 점수가 유지되어야 한다.
- 현재 점수가 기존 최고 점수보다 높으면 최고 점수를 갱신한다.

10. 화면 구성

[PC 화면]
- 상단: 게임 제목
- 상단 또는 게임판 위: SCORE / BEST
- 중앙: 게임판
- 하단: 방향키 안내 또는 게임 설명

[모바일 화면]
- 상단: 게임 제목
- 상단 또는 게임판 위: SCORE / BEST
- 중앙: 게임판
- 하단: 터치 방향 버튼

11. 디자인 컨셉
전체 디자인은 깔끔하면서도 귀여운 아케이드 게임 스타일로 제작한다.

디자인 방향:
- 복잡하지 않은 화면 구성
- 게임판 중앙 배치
- 둥근 모서리
- 은은한 그림자
- 뱀의 머리와 몸을 구분
- 뱀 머리에 작은 눈을 추가해 캐릭터처럼 표현
- 먹이는 한눈에 알아볼 수 있도록 강조
- 버튼에는 hover 효과 적용
- PC와 모바일 모두 보기 좋은 반응형 디자인

12. 주요 기능

- 게임 시작: START 버튼
- 캐릭터 이동: 방향키
- 먹이 생성: 랜덤 위치
- 뱀 성장: 먹을 때마다 몸 길이 +1
- 점수: 먹이당 +10
- 난이도: 점수에 따라 이동 속도 증가
- 충돌 판정: 벽 / 자기 몸
- 게임 오버: 충돌 시 종료
- 최고 점수: localStorage 저장
- 다시 시작: 게임 상태 초기화
- 모바일 조작: 터치 방향 버튼

13. 개발 환경

사용 기술:
- HTML
- CSS
- JavaScript

복잡한 프레임워크는 사용하지 않는다.

파일 구성:
snake-game/
- index.html

- game.js

14. 사용자 플레이 흐름

게임 접속
→ START 버튼 클릭
→ 방향키 또는 터치 버튼으로 뱀 이동
→ 먹이 발견
→ 먹이 획득
→ 점수 +10
→ 몸 길이 증가
→ 새로운 먹이 생성
→ 점수가 높아질수록 속도 증가
→ 벽 또는 자기 몸과 충돌
→ GAME OVER
→ 최종 점수 및 최고 점수 확인
→ 다시 시작
